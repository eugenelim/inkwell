# Digest format

The output contract for the brief. Tune wording and ordering here
without touching the workflow.

## The EA voice (every line)

- Lead with the hook — the ask or the key point — not who it's from
  (the sender is shown separately). Don't restate "this is an email
  from X."
- No meta-commentary ("discusses", "mentions", "highlights"). State
  it directly.
- For a NEEDS REPLY item, make the ask explicit and, where useful,
  suggest the next move: "Approve the Q3 budget — Dana needs sign-off
  before Thursday."
- Address the user in the second person: "You're being asked to…",
  "You still owe…".
- Strip opaque IDs, tracking tokens, long alphanumerics — keep only
  human-meaningful detail. (Message IDs go in the trailing citation,
  not the prose.)
- Compress newsletters/marketing/cold/automated mail to at most a
  one-line roundup, or omit.

## Template

> **Inbox brief — {date}**
> {N} threads in the last {window} · {X} need you · {Y} waiting ·
> rest is FYI/handled.
>
> **🔴 Needs your reply** (most important first)
> - [high] {hook with the ask, and suggested action} — *{sender}* `{id}`
> - [med] …
>
> **🟡 Waiting on others** (you're blocked / chasing)
> - {what you're waiting for, and how long it's been quiet} — *{sender}* `{id}`
>
> **🔵 Worth knowing** (no action needed)
> - {distilled point} — *{sender}* `{id}`
> - Newsletters/updates: {one-line roundup of the rest}
>
> **📅 Calendar** ({today / horizon})
> - {time} {event} — {conflict / prep-needed note if any}
>
> **✅ Handled / no action** — {count}, name only if notable.
>
> Hygiene: {unread total} unread · {screener pending} pending senders
> · reply-later {depth} · {flagged backlog} flagged.

## Rules

- At most ~5 items per section; if more, add "+{n} more".
- Keep the whole brief skimmable in under a minute.
- If a section is empty, omit it.
- If something is genuinely urgent or has a same-day deadline, call
  it out at the very top, before the summary line.
- If OOO is enabled or scheduled, mention it in one line at the end.
- If the gather ran on stale cache (sync failed), say so in the
  first line.
